# 열린기획 월간 일정표 v2 — Notion 읽기 전용 외부 달력

직원들이 아이폰·안드로이드에서 노션 「📅 월간일정표(Calander → 근무)」를 월간 달력으로 보는 웹페이지입니다.
**노션에는 조회만 하고, 일정을 쓰거나 수정·삭제하는 기능은 없습니다.**

## v1 → v2 바뀐 점
| 항목 | v1 | v2 |
|---|---|---|
| 조회 범위 | 보고 있는 달 + 다음 달 | **한국시간 기준 지난달·이번 달·다음 달 (3개월)**. 지난달 이전에 시작해 이어지는 일정도 표시 |
| 여러 날 일정 | 마지막 날이 빠지는 버그 | 노션과 같게 **종료일 포함** 표시 (왼쪽 굵은 띠) |
| 일정 색 | 모두 같은 색 | **업무속성별 색** (노션 선택지 색을 그대로 사용, 상단에 색 안내). 미지정은 흰색 |
| 처음 열 때 | 매번 처음부터 불러옴 | **저장된 일정 먼저 표시** → 최신 일정 조회 |
| 자동 갱신 | 없음 | 화면을 열어두면 **5분마다**, 다시 화면으로 돌아오면 1분 넘었을 때 갱신 |
| 월 이동 | 이동할 때마다 다시 조회 | **이미 받은 데이터로 즉시 표시** (서버 호출 없음) |
| 암호 | 열 때마다 다시 입력 | **기본은 암호 없음(누구나 보기)**. `CALENDAR_PASSWORD`를 넣으면 암호 사용, 한 번 입력 후 30일 유지 |
| 중복 요청 | 버튼 연타·월 이동 시 여러 개 | 화면에서 1개로 묶음 + 서버에서 1분 캐시, 동시 접속도 노션 조회 1회 |
| 갱신 실패 | 오류 문구만 | 기존 일정 유지 + **원인별 안내**(암호/노션 권한/노션 한도/노션 장애/인터넷 끊김), 노션 장애 시 직전 데이터로 대체 |
| 아이폰 | — | 입력칸 확대 방지, 노치 여백, 기기 시간대와 무관하게 한국시간 기준 |
| 설치 | express 필요 | **추가 패키지 없음** (Node.js 20 이상만 있으면 됨) |

## 배포 (Render 예시)
1. 이 폴더를 GitHub 저장소에 올리거나 Render에 직접 업로드합니다.
2. Render → New → **Web Service** → 저장소 선택
   - Runtime: Node / Build Command: (비워둠 또는 `npm install`) / Start Command: `npm start`
3. **Environment** 에 환경변수를 넣습니다.
   | 이름 | 값 | 필수 |
   |---|---|---|
   | `NOTION_API_KEY` | 노션 통합 비밀키 (`ntn_…`) | 필수 |
   | `CALENDAR_PASSWORD` | 직원용 달력 암호. **비워두면 암호 없이 누구나 보기** (현재 설정) | 선택 |
   | `NOTION_DATA_SOURCE_ID` | `272d2f7f-5131-8205-b193-87613435dcf2` | 생략 가능(기본값) |
   | `TOKEN_SECRET` | 아무 긴 임의 문자열 | 권장 |
4. 배포가 끝나면 `https://<주소>/calendar` 를 열어 일정 표시를 확인합니다. (`/`, `/calendar.html`도 같은 화면)
5. 노션 「모바일 월간일정 보기전용 캘린더」의 기존 임베드 주소를 새 주소로 바꿉니다. **기존 데이터베이스는 건드리지 않습니다.**

> 무료 요금제는 한동안 접속이 없으면 서버가 잠들어 첫 접속이 30초~1분 느릴 수 있습니다. 이때도 저장된 일정이 먼저 보입니다.

## 노션 통합 권한 (중요)
노션 `설정 → 연결 → 통합 관리`에서 이 달력용 통합의 **기능(Capabilities)을 "콘텐츠 읽기"만** 켜고, 업데이트·삽입은 끄세요.
코드에도 쓰기 기능이 없지만, 권한까지 읽기 전용이면 키가 새더라도 원본이 안전합니다.
그리고 `📅 Calander` 데이터베이스(또는 상위 `주)열린기획` 페이지)의 `…` → 연결 에 이 통합을 추가해야 조회됩니다.

## 운영 메모
- 현재는 **암호 없이 주소를 아는 누구나** 일정 제목을 볼 수 있습니다(수정은 불가). 다시 잠그려면 Render → Environment에 `CALENDAR_PASSWORD`를 추가하세요.
- **암호를 바꾸면** 모든 직원의 30일 로그인도 자동으로 풀리고 새 암호를 다시 묻습니다(분실 폰 대응 시 사용).
- 노션 호출량: 직원 수와 관계없이 **최대 1분에 1회 정도**(일정 1,000건 미만이면 1회당 요청 1~10번).
- 암호 연속 실패는 1분에 10회(IP당)로 차단됩니다.
- 일정 제목은 각 직원 폰의 브라우저에 저장됩니다(빠른 표시용). 공용 기기에서는 브라우저 기록을 지워 주세요.
- 노션 앱 안에서는 기기·앱 버전에 따라 저장소가 막혀 매번 암호를 물을 수 있습니다. 그런 경우 사파리/크롬에서 주소를 열고 **홈 화면에 추가**해 쓰면 가장 안정적입니다.
- 서버 상태 확인: `https://<주소>/healthz` → `{"ok":true}`

## 동작 확인 항목 (배포 후 실제 폰에서)
- [ ] 아이폰 사파리 / 노션 앱 임베드 / 안드로이드 크롬에서 열림

- [ ] 여러 날 일정의 마지막 날까지 표시
- [ ] 일정 누르면 노션 원본 페이지로 이동
